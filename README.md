## 올리는 법 (무료 · 도메인 없이)
```
1. 새 저장소 만들기 (예: soosoo-site) — 공개(public) 여야 GitHub Pages 가 무료다
2. index.html 을 올린다
3. Settings → Pages → Source: main / (root) → 저장
4. 몇 분 뒤 https://<계정>.github.io/soosoo-site/ 로 열린다  ← 이 주소를 구글에 넣는다
```
⚠️ **저장소가 공개된다** — 이 파일에는 사업자 정보(공개해도 되는 것)만 두고, 다른 문서는 넣지 않는다.

**도메인을 살 거면**: `soosoo.kr` 등을 사서 같은 파일에 연결하면 된다(연 2만원 안팎). 심사에 더 매끄럽고, 나중에
`contact@soosoo.kr` 같은 메일도 쓸 수 있다. **급하지 않다 — GitHub Pages 주소로도 구글은 받는다.**
